## C'est quoi ?

Un SMP lancé par Blasteur1916 et RedSavantMC pour regrouper une petite communauté autour du Minecraft survie. Pas de pay-to-win — juste du vanilla amélioré avec des gens sympas.

Chaque saison a un **twist secret** qui change complètement la dynamique de jeu.

## Rejoindre

1. Passe sur le [Discord](https://discord.gg/2RyQe7ZENA)
2. Lis le code de conduite
3. L'IP est donnée sur le serveur

**Prérequis :** Minecraft Java Edition 1.21 · Un compte Discord
